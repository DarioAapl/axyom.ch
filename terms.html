7. Security

Taking account of the state of the art, cost, and the risks to data subjects, we implement:

  • Encryption in transit — TLS on every connection.
  • Encryption at rest — the data volume is encrypted, and authorisation tokens are additionally encrypted at the application layer. API keys and session identifiers are stored only as cryptographic hashes.

  • Resilience and restoration — backups held on the same encrypted volume, restorable on request.
  • Testing — an automated test suite covering the security boundaries above runs before each deployment.
